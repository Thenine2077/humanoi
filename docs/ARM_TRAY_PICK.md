# แขน AR4 + หยิบกล่องตามกล้อง — สถานะ 26 ต.ค. 2026

สรุประบบที่ใช้อยู่ตอนนี้: ค่าชดเชยศูนย์ข้อต่อ (ตัวเลขในโปรแกรม = มุมจริง), สอนท่าจับกล่องแบบทางลัด,
และตัวหยิบกล่องตามที่กล้องเห็น — ทั้งหมดรันบน Pi (`arm ...`) โค้ดอยู่ใน repo นี้ + `humanoi-ar4-arm`

## 1. ค่าชดเชยศูนย์ข้อต่อ (zero trims)

ตำแหน่งข้อต่อมาจากการนับ step จากลิมิตสวิตช์ (ไม่มี encoder) ตัวเลขที่นับได้คลาดจากมุมจริงข้อละหลายองศา
แก้ที่บอร์ด: เฟิร์มแวร์ **AR4_ROS2_seq v3** เก็บค่าชดเชยใน EEPROM — มุมที่รายงาน = มุมที่นับได้ + ค่าชดเชย,
มุมที่สั่งลบค่าชดเชยก่อนหมุน · calibrate / ท่าพัก / ช่วงหมุนจริงไม่เปลี่ยน

| แขน | อ่านได้ตอนจัดตรงด้วยระดับน้ำ (J1..J6) | ค่าชดเชยในบอร์ด |
|---|---|---|
| ซ้าย | 7, 2, 0, 7, −19, −15 | −7, −2, 0, −7, +19, +15 |
| ขวา | 6, 12, 0, 3, 14, −15 | −6, −12, 0, −3, −14, +15 |

วิธีวัด: จัดข้อนั้นให้ตรงด้วยระดับน้ำ อ่านค่าในโปรแกรม r → ค่าชดเชย = **−r**

- ค่าทั้งหมดอยู่ที่เดียว: `ar4_ws/src/ar_dual/config/zero_trims.yaml` (repo `humanoi-ar4-arm`)
  - ลิมิตข้อต่อในโมเดล / ros2_control / `ar_program` เลื่อนตามค่านี้ (ช่วงหมุนจริงเท่าเดิม)
  - `after_calibrate`: หลัง `arm calibrate` ข้อ 1, 2, 4, 5, 6 หมุนต่อไปท่าตรง (0°) — ท่า rest ใน MoveIt ก็เป็นท่านี้
- `arm zero <left|right>` เขียนค่าจากไฟล์ลงบอร์ด · `arm start` ไม่ยอมเปิดถ้าบอร์ดไม่ตรงกับไฟล์
- **แฟลชบอร์ดใหม่ = EEPROM ถูกล้าง** (ชื่อแขน ทิศมอเตอร์ ค่าชดเชย) → ตั้งชื่อคืน (`ar_ports.py --name <port> left`)
  แล้ว `arm zero <แขน>` · ไม่ต้อง calibrate ใหม่ถ้าบอร์ดไม่ได้รีบูต
- เปลี่ยนค่าชดเชย = ท่าที่สอนไว้ของแขนนั้นต้องเลื่อนตาม (ทุกข้อพร้อมกัน บันทึกครั้งเดียว) ไม่งั้นท่าเดิมไปผิดที่

## 2. หยิบกล่องตามกล้อง

กล่อง 26.5×23.5×10 cm หูกล่อง 1×1 cm ด้านยาว · ป้าย ArUco id 1 ขนาด 120 mm แปะกลางพื้นกล่อง
(`docs/calibration/aruco_tray_id1_120mm.pdf`) · กล้อง Astra Pro ใต้คาง

```
arm start left        ระบบแขน
arm player            ตัวคุมมือ (นิ้ว tray_grip0 / tray_grip)
arm tray              กล้อง + หาตำแหน่งกล่อง (/tray/pose)
arm tray-teach        สอน (ครั้งเดียว)
arm tray-pick         หยิบ
```

### สอน — `arm tray-teach` (วิธี "ทางลัด")

ไม่ต้องรู้ตำแหน่งกล้อง: ใช้แค่ทิศกล้องเทียบแขน + ท่าจับจริงที่สอนไว้ แล้วเลื่อนมือตามระยะที่กล่องเลื่อน

1. **ท่าแตะ 4–6 ครั้ง (Enter)**: ปลายนิ้วแตะจุดเดิมบนกล่อง **ข้อมือมุมเดิมทุกครั้ง** (ใน RViz ลากแค่ลูกศรเลื่อน)
   ระหว่างครั้งเลื่อนกล่อง 3–7 cm สองทิศ ไม่หมุนกล่อง → ได้ทิศกล้องเทียบแขน (ครั้งที่ข้อมือ/กล่องหมุน ไม่ถูกใช้เอง)
2. **ท่าจับจริง (g)**: กล่องที่ตำแหน่งปกติ นิ้ว `tray_grip` จับหูกล่อง · สอนเพิ่มตอนกล่องเลื่อน = ครอบคลุมกว้างขึ้น
   และจะเห็นว่าท่าที่ 2 ทายจากท่าที่ 1 คลาดกี่ mm (ความแม่นจริง)
3. **w** บันทึก `humanoi_description/config/tray_grasp_left.yaml`

ผลตอนนี้: ท่าแตะ 5 ครั้ง ทิศกล้องแกว่ง ±3.9° · 2 ท่าจับ — ท่าที่ 2 ทายจากท่าที่ 1 คลาด **5.5 mm** (กล่องเลื่อน 32 mm หมุน 3°)

### หยิบ — `arm tray-pick`

`Enter` ดูแผน (ยังไม่ขยับ) → `y` หยิบ · `r` วางคืนที่เดิม · `h <cm>` ยกที่จับขึ้น/ลง (เก็บในไฟล์) · `q` ออก ·
Ctrl+C ระหว่างแขนขยับ = หยุด

1. นิ้ว `tray_grip0` → 2. ข้อมือไปรอเหนือที่จับ 8 cm → 3. ลงเส้นตรงตั้งฉากพื้นกล่อง → 4. นิ้ว `tray_grip`
→ 5. ยกขึ้นเส้นตรงแล้วค้างไว้

- ที่จับ = ท่าจับที่สอน (ตัวที่กล่องวางใกล้สุด) + ทิศกล้อง × (ป้ายตอนนี้ − ป้ายตอนสอน) ข้อมือมุมเดิม
- IK คำนวณเองจากโมเดลแขนที่ระบบใช้ (`humanoi_vision/arm_chain.py`) ไม่ต้องเปิด MoveIt · เช็ก FK เทียบ TF ทุกครั้ง
- ไม่หยิบเมื่อ: กล่องห่างท่าที่สอนเกิน 8 cm / หมุนเกิน 4° · ข้อมือเริ่มต่ำกว่าจุดรอ · ตัวเล่นโปรแกรมกำลังเล่น · ไม่มีตัวคุมมือ
- ยกขึ้นตรงๆ โดยข้อมือคงมุม ข้อ 5 พับจนชนลิมิต → ยก/รอได้เท่าที่ไปถึง (ตอนนี้ ~9–10 cm) ต่ำกว่า 4 cm ไม่หยิบ
- `grasp_offset_up` = 0.5 cm (หยิบจริงครั้งแรกจับต่ำไปนิด) — `tray-teach` บันทึกใหม่ไม่ล้างค่านี้

ทดสอบบน PC กับแขนจำลอง (ar_dual mock + controller จริง): ข้อมือถึงจุดจับที่คำนวณ คลาด 0.05 mm,
ลงเป็นเส้นตรง เบี้ยว < 0.1 mm · หยิบจริงครั้งแรก 26 ต.ค. จับได้

## 3. ยังไม่ได้ทำ / ข้อควรรู้

- **ชดเชยกล่องหมุนไม่ได้** (วิธีทางลัดไม่รู้ตำแหน่งกล้อง) — วางกล่องให้ตรง (ทำที่กั้น/เทปบนโต๊ะ)
- `camera_to_left_arm.yaml` บน Pi เป็นผลเก่า (22 ต.ค.) ที่ผิด — ตัวหยิบไม่ใช้ แต่ `/tray/pose_arm` และตำแหน่งกล้องใน RViz
  ยังใช้ไฟล์นี้
- แขนขวา: แฟลช v3 + ค่าชดเชยแล้ว ยังไม่ได้สอนท่าจับ · มือขวา (บอร์ด 5B91030501) ตัวคุมมือยังรองรับมือเดียว
- จุด B (พาไปวาง) พักไว้ก่อน — พื้นที่จำกัด
- แขนโหลดหนักตอนยื่นไกล (ข้อ 1 เคยรูด) — ความเร็วตั้งไว้ช้า: ข้อต่อ 0.15 rad/s, เส้นตรง 0.06 rad/s, เร่ง 0.08 rad/s²
