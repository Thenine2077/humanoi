# ภารกิจ A → B และฐานวิ่งอัตโนมัติ

หุ่นทำงานเป็นลำดับขั้นตามไฟล์ `ros2_ws/src/humanoi_mission/config/missions.yaml` — หยิบกล่องที่ A ด้วยกล้อง,
พับแขน, **รอคนยืนยันจากรีโมท**, ฐานวิ่งไป B, วาง, แล้วกลับ · คนคุมถือรีโมทตลอด หยุดได้ทุกเมื่อ

```
arm start · arm player · arm tray          แขน / มือ / กล้องหากล่อง (เหมือนตอนหยิบกล่อง)
arm base · arm lidar                       ฐานล้อ (Mega + encoder) / lidar กันชน
arm mission demo_ab                        เล่นภารกิจ (หน้าต่างแยก เปิดค้าง)
```

## ความปลอดภัย (งานจัดแสดง คนเยอะ)

| ชั้น | ทำงานยังไง |
|---|---|
| รอยืนยันก่อนฐานวิ่ง | ขั้น `confirm` = รอคนคุม **โยก SWB** (หรือ Enter ที่หน้าต่างภารกิจ) — ใส่ไว้ก่อนทุกช่วงที่ฐานวิ่ง |
| แขนพับก่อนฐานวิ่ง | ฐานไม่ยอมวิ่งถ้าแขนไม่อยู่ท่าใน `stow` (ห่างไม่เกิน 5° ทุกข้อ) |
| lidar กันชน | ของอยู่ในทางที่กำลังไปใกล้กว่า 0.35 m = หยุดรอจนโล่ง (ไม่อ้อม) · รอเกิน 15 วิ = เลิกภารกิจ · ไม่มี lidar = ฐานไม่วิ่ง |
| หยุดฉุกเฉิน | **โยก SWD** หรือ Ctrl+C = หยุดฐาน + หยุดแขน (ค้างท่า ไม่ตัดไฟ — ตัดไฟแล้วข้อ 1 ตก) + จบภารกิจ |
| รีโมทแย่งคุม | ขยับคันโยก / ปลด SWA / รีโมทดับ = Mega ตัดฐานเองทันที ภารกิจหยุดตาม |
| เช็กก่อนเริ่ม | ชื่อท่า/โปรแกรม/ท่ามือ/ไฟล์ท่าจับ และโปรแกรมที่ต้องเปิด ผิดหรือขาดสักอย่าง = ไม่เริ่มเลย และบอกว่าต้องทำอะไร |

## เตรียมครั้งแรก

1. **สอนท่าแขน** ที่ภารกิจใช้ (ชื่อในไฟล์เปลี่ยนได้):
   ```
   arm teach left carry_L     แขนซ้ายพับเข้าหาตัว ถือกล่อง (หลังหยิบ) — ศูนย์ถ่วงต่ำ ไม่ยื่นนอกฐาน
   arm teach left stow_L      แขนซ้ายพับ มือว่าง
   arm teach right stow_R     แขนขวาพับ
   arm teach left place_B     แขนซ้ายวางกล่องบนโต๊ะ B (จอดฐานที่ B ก่อนแล้วจัดท่า)
   ```
2. **ฐานวิ่งตามระยะ** — ลองทีละคำสั่ง ดูว่าไปได้จริงเท่าไหร่:
   ```
   arm drive forward 0.5      → "เดินหน้า 0.512 m จาก 0.500 m (เลย 1.2 cm) · เบี้ยวข้าง +0.8 cm · หัวหมุน +0.4°"
   arm drive turn 90
   ```
   เลยเป้าทุกครั้ง (ล้อไหลหลังตัด relay) → เพิ่ม `base.stop_early` / `base.stop_early_deg`
   เบี้ยวข้าง/หัวหมุนมาก → จูนลูกบิดล้อให้เท่ากันก่อน (`arm wheel-tune`)
3. **วัดเส้นทางจริง** A → B แล้วแก้ระยะ/มุมในขั้น `move` ของ `demo_ab`
4. ซ้อมทีละส่วน: `arm mission test_pick` (หยิบ-วางคืน ไม่ใช้ฐาน), `arm mission test_drive` (ฐานไป-กลับ 0.5 m)

ไฟล์ภารกิจอ่านใหม่ทุกครั้งที่สั่ง แก้แล้วเล่นได้เลย ไม่ต้อง build

## ขั้นที่ใช้ได้

| ขั้น | ตัวอย่าง | ทำอะไร |
|---|---|---|
| `confirm` | `confirm: "ทางไป B โล่งแล้ว"` | รอโยก SWB / Enter |
| `program` | `program: ready_pose` · `program: "@left:carry_L"` | เล่นโปรแกรมแขน / ไปท่าเดียว |
| `hand` | `hand: {left: tray_grip0}` | ท่ามือ |
| `pick` | `pick: left` | หยิบกล่องตามกล้อง (ท่าจับจาก `arm tray-teach`) |
| `place_back` | `place_back: left` | วางคืนที่หยิบมา |
| `move` | `move: {forward: 1.5}` · `move: {turn: -90}` | ฐาน forward back left right (m) · turn (องศา บวก = ซ้าย) |
| `wait` | `wait: 2` | รอ (วินาที) |

## ค่าของฐาน (พารามิเตอร์ `base.*` ของ base_move / mission)

| ค่า | ตั้งต้น | ความหมาย |
|---|---|---|
| `stop_early` / `stop_early_deg` | 0.03 m / 3° | ตัดก่อนถึงเป้าเท่านี้ (ล้อไหลต่อ) |
| `stop_dist` | 0.35 m | ของในทางใกล้กว่านี้ (จากขอบตัวหุ่น) = หยุดรอ — ตอนเข้าใกล้โต๊ะ B ตั้งให้เล็กลง |
| `footprint` | หน้า/หลัง 0.255, ซ้าย/ขวา 0.21 m | กรอบตัวหุ่น (ความกว้างยังเดา — วัดแล้วแก้) จุด lidar ในกรอบนี้ไม่นับ |
| `block_timeout` | 15 s | รอทางโล่งนานสุด |
| `odom_topic` | `/wheel_odom` | ระยะจาก encoder (ซิมใช้ `/odom`) |

ทดสอบแล้วในซิม Gazebo: วิ่ง/สไลด์/หมุนตามสั่ง, เจอกล่องขวางหยุดที่ 0.34 m, แขนไม่พับ = ฐานไม่วิ่ง,
SWB ยืนยันได้, SWD กลางทาง = หยุดทันที, Ctrl+C = หยุด · ยังไม่ได้ทดสอบกับฐานจริง (รอบอร์ด opto ของ encoder)
