ภาพรวมระบบ

Humanoi คือหุ่นยนต์ครึ่งตัวบนฐานล้อ ประกอบด้วยฐานล้อ mecanum ที่วิ่งได้ทุกทิศ (เดินหน้า ถอย สไลด์ข้าง หมุนตัว) แขนกล AR4 สองแขน และมือ AmazingHand สองมือ ทุกส่วนคุมจาก Raspberry Pi 5 ตัวเดียวที่รัน ROS 2 Jazzy อยู่ใน Docker คนคุมสั่งงานผ่านคำสั่งสั้นๆ ชื่อ arm ในหน้าต่าง terminal ของ Pi และถือรีโมท FlySky ไว้ขับฐานกับหยุดฉุกเฉิน

เป้าหมายของงานจัดแสดงคือ หุ่นหยิบกล่องที่จุด A แล้วนำไปวางที่จุด B — กล้องหาตำแหน่งกล่อง แขนหยิบ พับแขน ฐานวิ่งไป B โดยมี lidar คอยกันชน แล้ววางกล่อง ทุกช่วงที่ฐานจะวิ่งต้องมีคนยืนยันจากรีโมทก่อน

รูปถัดไปเป็นผังเดินสายของทั้งระบบ ได้แก่ สาย USB จาก Pi ผ่าน USB hub ไปยังแขน มือ กล้อง lidar และ Mega แหล่งจ่าย 5 V ของบอร์ดมือ แหล่งจ่าย 24 V ของฐาน และสายสัญญาณของ Mega ไปยังตัวรับรีโมท บอร์ด relay ตัวปรับความเร็ว มอเตอร์ และบอร์ดอ่าน encoder ถ้าต้องซูมดูขาต่อ เปิดไฟล์ขนาดเต็ม docs/SYSTEM_WIRING.pdf ใน repo

ระวัง บอร์ดมือสองตัวรับไฟจากแหล่งจ่าย 5 V ของมันเอง แยกจากแหล่งจ่าย 24 V ของฐาน ห้ามสลับสายหรือต่อ 24 V เข้าบอร์ดมือ เพราะ servo มือรับได้ 4.8–7.4 V ตัวคุมมือจะไม่เปิดแรงบิดถ้าไฟ servo ตัวใดอยู่นอกช่วงนี้ เช็กด้วย arm hand-scan ทุกครั้งที่ต่อไฟใหม่

โปรแกรมทำงานอยู่ที่ไหน

งานจริงทั้งหมดรันบน Pi ใน container ชื่อ humanoi_ros ส่วน PC ใช้เขียนโค้ด รันซิม (Gazebo) และดูภาพ/แผนที่ผ่าน Foxglove คำสั่ง arm รันบน Pi นอก container แล้วสั่งงานเข้าไปใน container ให้เอง จึงไม่ต้องจำคำสั่ง ROS ยาวๆ

Arduino Mega เป็นสมองชั้นล่างของฐานล้อ อ่านรีโมทและคุม relay เอง แม้ Pi ค้าง Mega ก็ยังหยุดล้อได้ ส่วน Pi ส่งคำสั่งให้ Mega ทาง USB เมื่อ ROS เป็นคนขับ (เช่น arm drive หรือภารกิจ)

ความปลอดภัย

หุ่นตัวนี้หนักและมีแขนที่แรงพอจะทำให้คนเจ็บได้ งานจัดแสดงมีคนเยอะ อ่านบทนี้ก่อนเปิดหุ่นทุกครั้งที่มีคนแปลกหน้าอยู่รอบๆ

กฎที่ห้ามละเลย

ระวัง ห้ามถอดหรือเสียบสาย USB ของแขนตอนไฟแขนเปิดอยู่ — ปิดไฟแขนก่อนเสมอ Pi 5 เคยเสียมาแล้วจากเรื่องนี้
ระวัง ตัดไฟแขนแล้วข้อ J1 ร่วงลง — ประคองแขนก่อนปิดไฟ หรือพาแขนไปท่าพักที่วางบนอะไรได้
ระวัง ไฟเซอร์โวมือห้ามเกิน 7.4V — เช็กด้วย arm hand-scan ก่อนสั่งมือขยับทุกครั้งที่ต่อไฟใหม่
ระวัง arm run / arm goto ไม่เช็กการชน (รวมสองแขนชนกันเอง) — โปรแกรมใหม่ลองด้วยความเร็วต่ำก่อนเสมอ
ระวัง เปิดรีโมทไว้ตลอดเวลาที่ฐานอาจวิ่ง รีโมทคือสวิตช์ฉุกเฉินของฐาน ปิดรีโมทหรือสัญญาณหลุด = ฐานหยุด
ระวัง แฟลชเฟิร์มแวร์ Mega ปิดไฟมอเตอร์ 24V ก่อน — ตอนรีเซ็ต relay อาจกระตุก
ระวัง ยังไม่มีปุ่ม E-stop ที่ตัดไฟมอเตอร์ — ระหว่างงานต้องมีคนถือรีโมทและเอื้อมถึงสวิตช์ไฟได้ตลอด

ก่อนเปิดให้คนดู

  1. กั้นพื้นที่ที่ฐานวิ่ง ให้คนดูอยู่นอกเส้น อย่างน้อย 1 m จากทางวิ่ง
  2. มีคนคุมหนึ่งคนถือรีโมท ไม่ทำอย่างอื่นพร้อมกัน
  3. เปิด arm lidar + arm base แล้วทดสอบกันชนวันนั้น: คนยืนหน้าหุ่น ขับรีโมทเข้าหาช้าๆ ต้องหยุดเอง (บท ระบบกันชน)
  4. เช็กพื้นทางวิ่ง: ไม่มีสาย กล่อง หรือของเตี้ยกว่า 23.5 cm — lidar มองไม่เห็นของเตี้ย
  5. เช็กไฟ: รีโมทแบตเต็ม ไฟเซอร์โวมือไม่เกิน 7.4V
  6. ซ้อมภารกิจทั้งรอบก่อนเปิดงานหนึ่งครั้ง

เปิด–ปิดหุ่น และรีโมท

ลำดับเปิดเครื่อง

  1. เช็กสายก่อนเปิดไฟใดๆ — USB ของแขน มือ Mega และ lidar เสียบที่ Pi ครบ (ย้ายสายแขนตอนไฟแขนเปิดไม่ได้)
  2. เปิด Pi รอราว 1 นาที container humanoi_ros ขึ้นเอง เช็กด้วย 
    arm status
  3. เปิดรีโมท แล้วโยก SWA ขึ้นหนึ่งครั้งแล้วลง (Mega ยอม ARM ต่อเมื่อเห็น SWA ขึ้นก่อน) ไฟ LED บน Mega ต้องเลิกกะพริบเร็ว
  4. เปิดไฟแขน แล้ว calibrate และเปิดระบบแขน (บท แขนกล AR4)
  5. เปิดส่วนที่งานนั้นต้องใช้ หน้าต่างละคำสั่ง ตามตารางข้างล่าง

หน้าต่างที่ต้องเปิดค้าง

คำสั่งพวกนี้ทำงานค้างไว้ ปิดด้วย Ctrl+C เปิดแต่ละตัวใน terminal ของมันเอง (ssh หลายหน้าต่าง หรือแท็บ)

คำสั่งทำอะไรต้องใช้กับ
arm startระบบแขนสองแขนทุกงานที่ขยับแขน
arm playerตัวเล่นโปรแกรม + มือarm run · ภารกิจ · หยิบกล่อง
arm trayกล้องหาตำแหน่งกล่องหยิบกล่อง · ภารกิจ
arm lidarlidarกันชน · arm drive · ภารกิจ
arm baseฐานล้อ + กันชนROS ขับฐาน · กันชนตอนขับรีโมท
arm mission <ชื่อ>เล่นภารกิจงาน A → B
arm rps …เกมเป่ายิ้งฉุบ (แทน arm player)เกม

ลำดับปิดเครื่อง

  1. หยุดงานที่ทำอยู่: arm stop หรือ Ctrl+C ที่หน้าต่างภารกิจ/เกม
  2. พาแขนไปท่าพัก แล้วปิดระบบแขน 
    arm off
  3. Ctrl+C หน้าต่าง arm base และ arm lidar (หลังปิด arm base รีโมทจะขับฐานไม่ได้จนกว่าจะโยก SWA ขึ้น-ลง — ตั้งใจให้เป็นแบบนั้น)
  4. ประคองแขน แล้วปิดไฟแขน (J1 ร่วง)
  5. ปิดไฟมอเตอร์ฐาน ปิด Pi (sudo shutdown now รอจนไฟบน Pi หยุดกะพริบก่อนถอดปลั๊ก) ปิดรีโมทเป็นอย่างสุดท้าย
