คู่มือใช้งานแขนกล AR4 สองแขน

หุ่นยนต์ Humanoi · Raspberry Pi 5 · ROS 2 Jazzy · คำสั่งลัด arm
ฉบับ 19 ตุลาคม 2026 (สองแขน) · ไฟล์ต้นฉบับ docs/AR4_ARM_COMMANDS.md

0ภาพรวมระบบ

หุ่นมีแขน AR4 สองตัวบนเสา เรียกตามด้านเมื่อมองจากตัวหุ่น: left = แขน 1 (ซ้าย) พิมพ์ left l 1 หรือ ซ้าย · right = แขน 2 (ขวา) พิมพ์ right r 2 หรือ ขวา

ทุกคำสั่งในคู่มือนี้พิมพ์ใน Terminal ของ Raspberry Pi นอก container ด้วยคำสั่งลัด arm เปิด Terminal ได้ 2 ทาง:

  • Raspberry Pi Connect → Screen sharing → กดไอคอน Terminal บนเดสก์ท็อป Pi (ต้องใช้ทางนี้ถ้าจะเปิด MoveIt)
  • จาก PC → ssh eitlaser@EIT-Raspberry-Pi-5.local

ลืมคำสั่ง พิมพ์ arm help · ดูว่าอะไรเปิดอยู่ พิมพ์ arm status

① เปิด

  1. arm status
  2. arm calibrate left / right (เมื่อจำเป็น)
  3. arm start หน้าต่าง 1
  4. arm player หน้าต่าง 2

② ใช้

  1. arm run ชื่อโปรแกรม
  2. arm moveit จัดท่า
  3. arm teach left ชื่อท่า
  4. arm remote 1 รีโมท

③ ปิด / หยุด

  1. arm stop หยุดโปรแกรม
  2. arm goto left rest / right rest
  3. arm off
  4. ปิดไฟแขน
ห้ามถอดหรือเสียบสาย USB ของแขนขณะไฟแขนเปิด ปิดไฟแขนก่อนทุกครั้ง (Pi 5 ตัวแรกเสียหลังถอดสาย Teensy ตอนไฟแขนเปิดอยู่ เมื่อ 19 ต.ค. 2026)
หยุดฉุกเฉิน: ปิดสวิตช์ไฟแขนเร็วที่สุด · คำสั่ง arm stop, ปุ่ม Stop ใน RViz และสวิตช์ SWD เป็นการหยุดทางซอฟต์แวร์ ใช้แทนสวิตช์ตัดไฟไม่ได้

1ตั้งค่าครั้งแรก

ทำครั้งเดียวเมื่อ: ใช้ Pi ตัวใหม่ · เปลี่ยนบอร์ด Teensy · แฟลชเฟิร์มแวร์ใหม่ ชื่อแขนและทิศมอเตอร์เก็บอยู่ในบอร์ด Teensy ของแต่ละแขน (เฟิร์มแวร์ AR4_ROS2_seq v2) ย้ายสาย USB ไปช่องไหนของ Pi ก็หาเจอเอง

  1. เช็กไฟย้อนก่อนต่อแขนเข้า Pi ใหม่: เปิดไฟแขน ยังไม่เสียบ USB เข้า Pi แล้ววัดแรงดันที่หัว USB-A ปลายสาย ระหว่างขา 5V (ขาริม) กับ GND (ขาริมอีกข้าง) ทุกเส้น (Teensy + Nano ทั้งสองแขน) ต้องได้ 0V ถ้าได้ ~5V ห้ามเสียบ ต้องแก้ก่อน (หรือใส่ USB isolator คั่น)
  2. ปิดไฟแขน → เสียบ USB ทุกเส้นเข้า Pi → เปิดไฟแขน
  3. arm ports ดูบอร์ด Teensy ทุกตัว: พอร์ต · เฟิร์มแวร์ (seq2) · ชื่อแขน · ข้อที่ตั้งกลับทิศ
  4. arm identify ตั้งชื่อบอร์ด: ข้อ 6 (ข้อมือ) ของแต่ละบอร์ดหมุนไป-กลับ 10° ทีละบอร์ด ดูว่าแขนไหนขยับ แล้วตอบ l = ซ้าย · r = ขวา · a = ขยับอีกที · s = ข้าม จบแล้วขึ้น left=... right=... = ใช้ได้ (ไม่เห็นอะไรขยับ = ไฟแขนปิดอยู่)
  5. หาลำดับ calibrate ที่มือไม่ชน (หัวข้อ 9) ไล่ทีละข้อ arm calibrate left 6, arm calibrate left 5, ... ได้ลำดับที่ปลอดภัยแล้วตั้งเป็นค่าเริ่ม LEFT_CAL_ORDER / RIGHT_CAL_ORDER ใน ~/Humanoi/scripts/arm.sh
  6. ข้อไหนขึ้น ✗ ... FAIL = มอเตอร์ข้อนั้นหมุนกลับด้าน → arm dir right 000010 (ตัวอย่าง: J5 กลับทิศ) แล้ว calibrate ข้อนั้นใหม่
  7. หลัง calibrate ครั้งแรก แขนอยู่ท่าพัก → arm start แล้วบันทึกท่าพักของแขนที่ยังไม่มี: arm teach right rest
เช็กซ้ำว่าชื่อตรงกับแขนจริงได้ทุกเมื่อ: arm identify left ข้อ 6 ของแขนซ้ายจะหมุนให้ดูแขนเดียว (ระบบแขนต้องปิดอยู่)

5สร้างท่าด้วย MoveIt

เปิด MoveIt

  1. เปิดระบบแขนไว้ก่อน (arm start) MoveIt สั่งแขนผ่านระบบนี้
  2. เปิด Raspberry Pi Connect → Screen sharing ให้เห็นเดสก์ท็อป Pi
  3. บนเดสก์ท็อป Pi กดไอคอน Terminal (รูปจอดำ >_ แถบบนซ้าย)
  4. พิมพ์ arm moveit แล้ว Enter รอ 20–30 วินาที หน้าต่าง RViz ขึ้นพร้อมโมเดลสองแขน เสา หัว และกล้อง
  5. ปล่อยหน้าต่าง Terminal นี้เปิดไว้ (ปิด MoveIt = Ctrl+C ในหน้าต่างนี้)

ขึ้น ✗ เปิดระบบแขนก่อน = ยังไม่ได้ arm start · RViz ไม่ขึ้น = เดสก์ท็อป Pi ยังไม่ได้ล็อกอิน (ต้องเห็นหน้าจอใน Pi Connect ก่อน)

จัดท่าและบันทึก

  1. แผง MotionPlanning → ช่อง Planning Group เลือก left_arm, right_arm หรือ both_arms
  2. แท็บ Joints เลื่อนมุมทีละแกน (หรือลากลูกบอลที่ปลายแขน) แขนสีส้มโปร่งขยับให้ดูก่อน แขนจริงยังไม่ขยับ
  3. แท็บ Planning → Velocity Scaling ตั้งไว้ 0.3 (อย่าเกิน) → กด Plan & Execute → แขนจริงขยับ · ตอน Plan, MoveIt เช็กการชนแขนกับแขน และแขนกับเสา/หัว/กล้องให้ ถ้าชนจะ Plan ไม่ผ่าน
  4. แขนถึงท่าแล้ว ในอีกหน้าต่างพิมพ์ arm teach left ชื่อท่า (หรือ right)
  5. ทำซ้ำทุกท่า → arm program ... → ทดสอบ arm run ชื่อโปรแกรม

เปิดค้างไว้ แสดงทุกครั้งที่โยกสวิตช์ และผลจากแขน (แขนรายงาน: 1:ok)

ระบบกันสั่งมั่ว

  • สั่งเฉพาะจังหวะโยก สวิตช์ค้างไว้ไม่สั่งซ้ำ
  • เปิดระบบตอนสวิตช์อยู่ล่าง = ไม่สั่ง ต้องเห็นสวิตช์อยู่บนก่อน
  • รีโมทดับหรือหลุดสัญญาณ = ไม่สั่ง และหลังสัญญาณกลับมาต้องดันสวิตช์ขึ้นก่อน
  • แขนกำลังเล่นโปรแกรมอยู่แล้วสั่งซ้ำ = ถูกปฏิเสธ (rejected:busy) ไม่ซ้อนกัน

arm remote เปิด relay_bridge (คุยกับ Mega) ให้ด้วยถ้ายังไม่ได้เปิด กด Ctrl+C ปิดทั้งคู่ · รีโมทยังขับฐานได้ตามปกติ · ถ้ายังไม่ได้เปิด arm player ก็ทดสอบสวิตช์ได้ เห็นผลบนจอแต่แขนไม่ขยับ

8ปิดระบบ

  1. ให้แขนกลับท่าพักก่อน: arm goto left rest และ arm goto right rest (หรือสร้างโปรแกรม arm program park rest/rest แล้ว arm run park)
  2. arm off ปิดทุกอย่างของแขน (หรือกด Ctrl+C ทีละหน้าต่าง)
  3. ปิดไฟแขน

9Calibrate

ต้อง calibrate เมื่อ

  • ปิดไฟแขน (รวมทุกครั้งที่ต้องถอด/เสียบ USB เพราะต้องปิดไฟแขนก่อน)
  • แฟลชเฟิร์มแวร์ Teensy ใหม่ หรือเปลี่ยนทิศมอเตอร์ด้วย arm dir
  • แขนชนอะไร หรือสายพานรูด

Teensy นับตำแหน่งจากสเต็ปที่สั่งมอเตอร์ ไม่ได้วัดจริง ถ้าเกิดเรื่องข้างบน ตำแหน่งที่จำไว้จะไม่ตรงกับแขนจริง ถ้าไม่เกิดให้ข้ามไป arm start ได้เลย · calibrate ได้เฉพาะตอนระบบแขนปิดอยู่

ระหว่าง calibrate

  • ครั้งแรกหลังย้ายสาย ดูให้แน่ใจว่าแขนที่ขยับคือแขนที่สั่ง ไม่ใช่ หรือมือกำลังจะชน ให้ปิดไฟแขนทันที
  • รอบแขนโล่ง สาย USB หย่อนพ้นรัศมีแขน ฐาน J1 หมุนไปถึง −170° อีกแขนต้องไม่อยู่ในทาง
  • ข้อที่ไม่ได้สั่งไม่ขยับ แต่ถ้าเพิ่งเปิดไฟแขน ต้อง calibrate ให้ครบ 6 ข้อก่อนใช้งาน
  • จบเมื่อขึ้น calibrate ครบตามที่สั่งแล้ว ไม่ต้องกด Ctrl+C

# หาพอร์ต / ตั้งชื่อบอร์ด (ระบบแขนต้องปิดอยู่)
ros2 run ar_dual ar_ports.py --list
ros2 run ar_dual ar_ports.py                 # พิมพ์ left=<พอร์ต> right=<พอร์ต>
ros2 run ar_dual ar_ports.py --identify
ros2 run ar_dual ar_ports.py --dir <พอร์ต> 000010
# calibrate (ทีละแขน)
ros2 run ar_dual ar_calibrate.py <พอร์ตแขน> 6 5 4 1 2 3
# เปิดระบบสองแขน (left_hw/right_hw = real | mock)
ros2 launch ar_dual dual_hardware.launch.py left_port:=<พอร์ตซ้าย> right_port:=<พอร์ตขวา> left_hw:=real right_hw:=real
# ตัวเล่นโปรแกรม
ros2 launch ar_program arm_program.launch.py speed:=0.19
# สั่งงาน
ros2 topic pub --once /arm/run std_msgs/msg/String "{data: pick2}"
ros2 topic pub --once /arm/run std_msgs/msg/String "{data: '@right:rest'}"   # = arm goto right rest
ros2 topic pub --once /arm/stop std_msgs/msg/Empty "{}"
ros2 run ar_program teach --list
ros2 run ar_program teach --show pick2
ros2 run ar_program teach <ชื่อท่า> --arm left
ros2 run ar_program teach --program pick2 rest/rest act1/- wait=1.0 -/act2
ros2 run ar_program teach --delete <ชื่อท่า> --arm right
ros2 run ar_program teach --delete-program pick2
