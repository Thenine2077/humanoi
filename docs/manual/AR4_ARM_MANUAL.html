ทุกคำสั่งในคู่มือนี้พิมพ์ใน Terminal ของ Raspberry Pi นอก container ด้วยคำสั่งลัด arm เปิด Terminal ได้ 2 ทาง:

  • Raspberry Pi Connect → Screen sharing → กดไอคอน Terminal บนเดสก์ท็อป Pi (ต้องใช้ทางนี้ถ้าจะเปิด MoveIt)
  • จาก PC → ssh eitlaser@192.168.1.68

ลืมคำสั่ง พิมพ์ arm help · ดูว่าอะไรเปิดอยู่ พิมพ์ arm status

① เปิด

  1. arm status
  2. arm calibrate (เมื่อจำเป็น)
  3. arm start หน้าต่าง 1
  4. arm player หน้าต่าง 2

② ใช้

  1. arm run demo
  2. arm moveit จัดท่า
  3. arm teach ชื่อท่า
  4. arm remote 1 รีโมท

③ ปิด / หยุด

  1. arm stop หยุดโปรแกรม
  2. arm run demo กลับท่าพัก
  3. arm off
  4. ปิดไฟแขน
หยุดฉุกเฉิน: ปิดสวิตช์ไฟแขนเร็วที่สุด · คำสั่ง arm stop, ปุ่ม Stop ใน RViz และสวิตช์ SWD เป็นการหยุดทางซอฟต์แวร์ ใช้แทนสวิตช์ตัดไฟไม่ได้

3สร้างท่าด้วย MoveIt

เปิด MoveIt

  1. เปิดระบบแขนไว้ก่อน (arm start) MoveIt สั่งแขนผ่านระบบนี้
  2. เปิด Raspberry Pi Connect → Screen sharing ให้เห็นเดสก์ท็อป Pi
  3. บนเดสก์ท็อป Pi กดไอคอน Terminal (รูปจอดำ >_ แถบบนซ้าย)
  4. พิมพ์ arm moveit แล้ว Enter รอ 20–30 วินาที หน้าต่าง RViz จะขึ้นพร้อมแผง MotionPlanning และโมเดลแขน
  5. ปล่อยหน้าต่าง Terminal นี้เปิดไว้ (ปิด MoveIt = Ctrl+C ในหน้าต่างนี้)

ขึ้น ✗ เปิดระบบแขนก่อน = ยังไม่ได้ arm start · RViz ไม่ขึ้น = เดสก์ท็อป Pi ยังไม่ได้ล็อกอิน (ต้องเห็นหน้าจอใน Pi Connect ก่อน)

จัดท่าและบันทึก

  1. แผง MotionPlanning → แท็บ Joints เลื่อนมุมทีละแกน (หรือลากลูกบอลที่ปลายแขน) แขนสีส้มโปร่งขยับให้ดูก่อน แขนจริงยังไม่ขยับ
  2. แท็บ Planning → Velocity Scaling ตั้งไว้ 0.3 (อย่าเกิน) → กด Plan & Execute → แขนจริงขยับ
  3. แขนถึงท่าแล้ว ในอีกหน้าต่างพิมพ์ arm teach ชื่อท่า
  4. ทำซ้ำทุกท่า → arm program ชื่อโปรแกรม ท่า1 ท่า2 ... → ทดสอบ arm run ชื่อโปรแกรม

4แก้ไขและลบ ท่า/โปรแกรม

อยากทำทำยังไง
แก้ท่าเดิมarm goto ท่า → ปรับใน MoveIt (Joints → Plan & Execute) → arm teach ชื่อเดิม บันทึกทับ ระบบแสดงค่าเก่า/ใหม่ให้เทียบ ทุกโปรแกรมที่ใช้ท่านี้ได้ค่าใหม่ทันที
แก้ลำดับในโปรแกรมarm program ชื่อเดิม ท่าใหม่ทั้งหมด... สั่งทับได้เลย
ลบท่าที่โปรแกรมยังใช้ระบบไม่ยอมและบอกว่าโปรแกรมไหนใช้อยู่ แก้หรือลบโปรแกรมนั้นก่อน แล้วค่อย arm delete
เปลี่ยนชื่อท่าarm goto ชื่อเก่า → arm teach ชื่อใหม่ → แก้โปรแกรมให้ใช้ชื่อใหม่ → arm delete ชื่อเก่า
ลบโปรแกรมarm delete-program ชื่อ (ท่าที่อยู่ในโปรแกรมไม่หาย)
แก้ท่าหรือโปรแกรมแล้วไม่ต้องรีสตาร์ทอะไร ตัวเล่นโปรแกรมอ่านไฟล์ใหม่ทุกครั้งที่สั่ง ยกเว้นหลังอัปเดตโปรแกรมของระบบเอง (เช่นตอนเพิ่มคำสั่ง arm goto) ต้องปิดแล้วเปิด arm player ใหม่หนึ่งครั้ง

เปิดค้างไว้ แสดงทุกครั้งที่โยกสวิตช์ และผลจากแขน (แขนรายงาน: 1:ok)

ระบบกันสั่งมั่ว

  • สั่งเฉพาะจังหวะโยก สวิตช์ค้างไว้ไม่สั่งซ้ำ
  • เปิดระบบตอนสวิตช์อยู่ล่าง = ไม่สั่ง ต้องเห็นสวิตช์อยู่บนก่อน
  • รีโมทดับหรือหลุดสัญญาณ = ไม่สั่ง และหลังสัญญาณกลับมาต้องดันสวิตช์ขึ้นก่อน
  • แขนกำลังเล่นโปรแกรมอยู่แล้วสั่งซ้ำ = ถูกปฏิเสธ (rejected:busy) ไม่ซ้อนกัน

arm remote เปิด relay_bridge (คุยกับ Mega) ให้ด้วยถ้ายังไม่ได้เปิด กด Ctrl+C ปิดทั้งคู่ · รีโมทยังขับฐานได้ตามปกติ · ถ้ายังไม่ได้เปิด arm player ก็ทดสอบสวิตช์ได้ เห็นผลบนจอแต่แขนไม่ขยับ

6ปิดระบบ

  1. ให้แขนกลับท่าพักก่อน: arm run demo (จบที่ท่าพัก) หรือ arm goto rest
  2. arm off ปิดทุกอย่างของแขน (หรือกด Ctrl+C ทีละหน้าต่าง)
  3. ปิดไฟแขน

7Calibrate

ต้อง calibrate เมื่อ

  • ปิดไฟแขน หรือถอดสาย USB ของ Teensy
  • แฟลชเฟิร์มแวร์ Teensy ใหม่
  • แขนชนอะไร หรือสายพานรูด

Teensy นับตำแหน่งจากสเต็ปที่สั่งมอเตอร์ ไม่ได้วัดจริง ถ้าเกิดเรื่องข้างบน ตำแหน่งที่จำไว้จะไม่ตรงกับแขนจริง ถ้าไม่เกิดให้ข้ามไป arm start ได้เลย

ระหว่าง calibrate (~2 นาที)

  • รอบแขนโล่ง สาย USB หย่อนพ้นรัศมีแขน ฐาน J1 หมุนไปถึง −170°
  • แขนหมุนทุกแกนไปชนสวิตช์ → หยุด 2 วินาที → ถอยออก → กลับท่าพัก
  • log เงียบ หรือขึ้น error / Failed to acquire lock ก็ได้ Teensy ทำต่อจนจบเอง
  • ห้ามกด Ctrl+C จนกว่าแขนจะหยุดนิ่งที่ท่าพัก

8ค่าที่ตั้งไว้และความปลอดภัย

รายการค่า / หมายเหตุ
ความเร็วตัวเล่นโปรแกรม0.19 rad/s (ฐานหมุน ~11°/วินาที เท่ากับตอน calibrate) เพดาน 0.22 สั่งเกินจะถูกลดลงเอง เร่งและเบรก 4.6°/วินาที²
ความเร็ว MoveItVelocity Scaling 0.3 (อย่าตั้งเกิน)
สายพาน J1เคยรูดตอนแขนยื่นไกลแล้วหมุนฐานเร็ว ท่าที่ยื่นแขนสุดและหมุนฐานไกล (เช่น home, pick_frot) ให้ทดสอบช้าๆ และให้ช่างตรวจความตึงสม่ำเสมอ
ท่าพัก (rest)J2 = −5.8°, J5 = −52.2° แกนอื่น 0°
การหยุดฉุกเฉินจริงสวิตช์ตัดไฟแขน · คำสั่งหยุดทางซอฟต์แวร์ใช้แทนไม่ได้

ขอบเขตแต่ละแกน (ตัวเล่นโปรแกรมตรวจทุกท่าก่อนขยับ)

แกนJ1 ฐานJ2 ไหล่J3 ศอกJ4J5J6
องศา±170−42 ถึง +90−89 ถึง +52±165±105±155
