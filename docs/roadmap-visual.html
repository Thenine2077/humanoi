Humanoi · Roadmap

จากคีย์บอร์ดสั่งล้อ ถึงแขนกลสองข้างทำงานเอง

โรดแมป 18 ขั้นของฐานเคลื่อนที่ 4 ล้อ mecanum ที่จะติดแขนกล AR4 สองแขนไว้ด้านบน — พิสูจน์ทุกพฤติกรรมในซิมก่อน แล้วค่อยย้ายลงฮาร์ดแวร์จริงทีละชั้น

ROS 2 Jazzy Gazebo Harmonic มอเตอร์ mecanum ×4 แขน AR4 ×2
7/ 18 ขั้นผ่านแล้ว
M8 กำลังทดสอบ
ซอฟต์แวร์ / ซิม — M1–M10ฐานจริง — M11–M14แขน + รวมร่าง — M15–M18
ซอฟต์แวร์ / จำลอง M1 – M10 · พิสูจน์ pipeline ทั้งหมดในซิมก่อนแตะฮาร์ดแวร์
กำลังทำ
M01

คีย์บอร์ด → หุ่น mecanum ใน Gazebo ขยับถูกทิศทุกปุ่ม ปล่อยปุ่ม 0.5 วิ = หยุด

M02

ขับสี่เหลี่ยม 2×2 ม. กลับจุดเดิม — odom คลาดเคลื่อน < 5%

M03

serial ↔ Arduino MEGA relay H-bridge 1 มอเตอร์ · watchdog 500ms · dead-time

M3b — ขยับเป็น 4 ล้อ mecanum, relay 8 ตัว, มิกซ์ทิศถูกสูตรครบ

M04

Gazebo + มอเตอร์จริง สั่งจากคีย์บอร์ดตัวเดียว เดินหน้า/ถอยพร้อมกัน

M05

LiDAR จำลอง 360° / 12 ม. ในโลกห้อง 10×8 ม. + สิ่งกีดขวาง

M06

slam_toolbox สร้างแผนที่ 199×159 พิกเซล @ 5 ซม.

M07

Nav2 (AMCL + planner + controller) วางเส้นทางไป goal สำเร็จ

M08ตอนนี้

หลบสิ่งกีดขวางที่ไม่อยู่ในแผนที่ — costmap จาก /scan reroute เอง

ทดสอบ 2 แบบ: กล่องนิ่งวางขวาง และคนเดินตัดหน้าวนซ้ำอัตโนมัติ

M09

Nav2 holonomic เต็มรูปแบบ (MPPI เปิด vy) — สไลด์เข้า goal ไม่ต้องหมุนก่อน

M10

humanoi_mission orchestrator — ลาดตระเวน waypoint วนลูปเอง

ฐานจริงนำทาง M11 – M14 · ย้าย pipeline เดียวกันลงฮาร์ดแวร์จริง
รอฮาร์ดแวร์
M11

rf2o laser odometry บนฐานจริง (มอเตอร์ยังไม่มี encoder)

M12

ESP32 + Cytron MDDS10 ×2 — คุมความเร็ว 4 ล้อจาก ROS ได้จริง (ไม่ใช่ลูกบิด)

M13

Nav2 บนฐานจริงในห้องจริง — หลบสิ่งกีดขวางจริงได้เหมือนในซิม

M14

dead-wheel pod ×2–3 + IMU → EKF ผสาน odometry ให้แม่นตอนวิ่งเร็ว/สไลด์

แขน AR4 + รวมร่าง M15 – M18 · ปลายทาง — ฐาน + แขน ×2 ทำงานร่วมกัน
รอฮาร์ดแวร์
M15

แขน AR4 ในซิม (MoveIt 2) ติดบน base_link เล่นท่า pre-program ได้

M16

ฐาน + แขน ในซิมเดียว — interlock: แขนต้องพับก่อนฐานวิ่ง

M17

แขน AR4 จริง (Teensy 4.1 + ar4_ros_driver) + gripper แยก

M18

Raspberry Pi 5 คุม mission ผสาน Nav2 + MoveIt · RC override ได้ตลอดเวลา

ทำไมต้องเรียงแบบนี้: ฐานเคลื่อนที่ต้องนำทางได้เองก่อน แขนถึงจะมีที่ยืนให้ทำงาน — ทุกขั้นพิสูจน์ในซิมก่อนเสมอ ก่อนย้ายลงฮาร์ดแวร์จริงทีละชั้น เพื่อลดความเสี่ยงตอนแขนกับฐานต้องทำงานพร้อมกัน
