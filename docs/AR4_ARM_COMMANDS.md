# คู่มือคำสั่งแขน AR4 บน Raspberry Pi

ทุกคำสั่งพิมพ์ใน **Terminal ของ Pi** (นอก container) — เปิดได้ 2 ทาง:

- **Raspberry Pi Connect** → Terminal บนเดสก์ท็อป Pi (ต้องใช้ทางนี้ถ้าจะเปิด MoveIt)
- **จาก PC:** `ssh eitlaser@192.168.1.68`

พิมพ์ `arm help` เพื่อดูรายการคำสั่งทั้งหมดได้ตลอด

---

## 1. เริ่มใช้งาน

คำสั่งที่ "เปิดค้าง" ต้องใช้ **หน้าต่างละคำสั่ง** และห้ามปิดหน้าต่างระหว่างใช้งาน

| ขั้น | หน้าต่าง | คำสั่ง | หมายเหตุ |
|---|---|---|---|
| 0 | ไหนก็ได้ | `arm status` | ดูว่าอะไรเปิดอยู่ — ระบบแขนต้องเป็น ✗ ก่อนเริ่ม |
| 1 | หน้าต่าง 1 | `arm calibrate` | **เฉพาะเมื่อจำเป็น** (ดูหัวข้อ 4) — รอแขนกลับท่าพักแล้วนิ่ง แล้วกด `Ctrl+C` |
| 2 | หน้าต่าง 1 | `arm start` | เปิดระบบแขน — **เปิดค้างไว้** |
| 3 | หน้าต่าง 2 | `arm player` | เปิดตัวเล่นโปรแกรม — **เปิดค้างไว้** |
| 4 | หน้าต่าง 3 (บนเดสก์ท็อป Pi) | `arm moveit` | เปิด MoveIt + RViz — เฉพาะตอนจะจัดท่า (ดูหัวข้อ "จัดท่าด้วย MoveIt") |

### ลำดับเต็ม แบบต้อง calibrate

```text
หน้าต่าง 1:  arm calibrate   → กด Enter → รอแขนกลับท่าพักและนิ่ง (~2 นาที) → Ctrl+C
หน้าต่าง 1:  arm start       → (หน้าต่างเดิม) เปิดค้างไว้
หน้าต่าง 2:  arm player      → เปิดค้างไว้
หน้าต่าง 3:  arm run demo    → ทดสอบ (หรือ arm moveit บนเดสก์ท็อป Pi ถ้าจะจัดท่า)
```

### ลำดับเต็ม แบบไม่ต้อง calibrate

```text
หน้าต่าง 1:  arm start       → เปิดค้างไว้
หน้าต่าง 2:  arm player      → เปิดค้างไว้
หน้าต่าง 3:  arm run demo
```

หลังกด Ctrl+C ที่ calibrate ถ้า `arm start` ขึ้นว่า "ระบบแขนเปิดอยู่แล้ว" ให้รอ ~15 วินาทีแล้วสั่งใหม่
(ตัวเก่ายังปิดตัวไม่เสร็จ)

## 2. ใช้งาน (หน้าต่างไหนก็ได้)

| ทำอะไร | คำสั่ง |
|---|---|
| เล่นโปรแกรม (รอจนจบแล้วบอกผล) | `arm run demo` |
| หยุดโปรแกรมกลางคัน | `arm stop` |
| ดูท่าและโปรแกรมทั้งหมด | `arm list` |
| บันทึกท่าปัจจุบันของแขน | `arm teach pick_above` |
| สร้างโปรแกรม | `arm program pick rest pick_above wait=1.0 rest` |
| พาแขนไปท่าเดียว | `arm goto pick_above` |
| ลบท่า (ต้องไม่มีโปรแกรมไหนใช้อยู่) | `arm delete pick_above` |
| ลบโปรแกรม (ท่าในโปรแกรมยังอยู่) | `arm delete-program pick` |

### แก้ท่า / แก้โปรแกรม

| อยากทำ | ทำยังไง |
|---|---|
| **แก้ท่าเดิม** | `arm goto <ท่า>` → ปรับใน MoveIt (แท็บ Joints → Plan & Execute) → `arm teach <ชื่อเดิม>` (ทับของเดิม แสดงค่าเก่า/ใหม่ให้ดู) |
| **แก้ลำดับในโปรแกรม** | สั่ง `arm program <ชื่อเดิม> <ท่าใหม่ทั้งหมด...>` ทับได้เลย |
| **ลบท่าที่โปรแกรมยังใช้อยู่** | ระบบจะไม่ยอมและบอกว่าโปรแกรมไหนใช้ — แก้/ลบโปรแกรมนั้นก่อน แล้วค่อย `arm delete` |
| **เปลี่ยนชื่อท่า** | `arm goto <ชื่อเก่า>` → `arm teach <ชื่อใหม่>` → แก้โปรแกรมให้ใช้ชื่อใหม่ → `arm delete <ชื่อเก่า>` |

แก้ไฟล์ท่าแล้วไม่ต้องรีสตาร์ทอะไร — ตัวเล่นโปรแกรมอ่านไฟล์ใหม่ทุกครั้งที่สั่ง

**หยุดฉุกเฉิน:** ปิดสวิตช์ไฟแขน (เร็วที่สุด) หรือ `arm stop`

### จัดท่าด้วย MoveIt (RViz บนจอ Pi)

**เปิด MoveIt**

1. เปิดระบบแขนไว้ก่อน (`arm start` ในหน้าต่าง 1) — MoveIt สั่งแขนผ่านระบบนี้
2. เปิด **Raspberry Pi Connect → Screen sharing** ให้เห็นเดสก์ท็อป Pi
3. บนเดสก์ท็อป Pi กดไอคอน **Terminal** (รูปจอดำ `>_` แถบบนซ้าย) เปิดหน้าต่างใหม่
4. พิมพ์ `arm moveit` แล้ว Enter — รอ 20–30 วินาที หน้าต่าง **RViz** จะขึ้นพร้อมแผง MotionPlanning และโมเดลแขน
5. ปล่อยหน้าต่าง Terminal นี้เปิดไว้ (ปิด MoveIt = กด `Ctrl+C` ในหน้าต่างนี้)

ถ้าขึ้น `✗ เปิดระบบแขนก่อน` = ยังไม่ได้ `arm start` · ถ้า RViz ไม่ขึ้น = เดสก์ท็อป Pi ยังไม่ได้ล็อกอิน
(ต้องเห็นหน้าจอใน Pi Connect ก่อน) · สั่งจาก ssh บน PC ก็ได้ แต่หน้าต่าง RViz จะไปขึ้นบนจอ Pi ไม่ใช่บน PC

**จัดท่าและบันทึก**

1. แผง MotionPlanning → แท็บ **Joints** เลื่อนมุมทีละแกน (หรือลากลูกบอลที่ปลายแขน) — แขนสีส้มโปร่งขยับให้ดูก่อน แขนจริงยังไม่ขยับ
2. แท็บ **Planning** → Velocity Scaling ตั้งไว้ **0.3** แล้ว (อย่าเกิน 0.3) → กด **Plan & Execute** → **แขนจริงขยับ**
3. แขนถึงท่าแล้ว เปิดอีกหน้าต่าง: `arm teach <ชื่อท่า>` (ใช้ชื่อภาษาอังกฤษ)
4. ทำซ้ำทุกท่า แล้ว `arm program <ชื่อโปรแกรม> <ท่า...>` → ทดสอบ `arm run <ชื่อโปรแกรม>` (ต้องเปิด `arm player` ไว้)

ปุ่ม **Stop** ในแผง Planning หยุดแขนกลางทางได้ · ฉุกเฉินปิดสวิตช์ไฟแขน

ตอนเล่นโปรแกรม แขนเดินตรงจากท่าหนึ่งไปอีกท่า (ทุกแกนเริ่ม-จบพร้อมกัน) ไม่ได้เดินตามเส้นทางที่ MoveIt
วางไว้ตอนจัดท่า — เล่นรอบแรกให้ดูว่าไม่เฉียดอะไร ถ้าเฉียดให้เพิ่มท่าคั่นกลาง

**ลำดับเต็มตอนจัดท่า**

```text
หน้าต่าง 1:                    arm start       → เปิดค้าง
หน้าต่าง 2:                    arm player      → เปิดค้าง
หน้าต่าง 3 (เดสก์ท็อป Pi):     arm moveit      → เปิดค้าง (RViz ขึ้นบนจอ Pi)
หน้าต่าง 4:                    arm teach ...   / arm program ... / arm run ...
```

### สั่งจากรีโมท FlySky (SWB / SWD)

| สวิตช์ | ทำอะไร |
|---|---|
| **CH6** (ตอนนี้คือ **SWC** 3 ระดับ) บนสุด → ล่างสุด | เล่นโปรแกรม `1` (ครั้งเดียวต่อการโยกหนึ่งครั้ง) — ตำแหน่งกลางไม่นับ |
| **CH8** (**SWD**) ขึ้น → ลง | หยุดแขนทันที — และระหว่างที่ SWD ลงค้างอยู่ สั่งเล่นไม่ได้ |

**ต้องมี:** Mega เสียบ USB เข้า Pi · รีโมทเปิดอยู่ · `arm start` และ `arm player` เปิดอยู่ แล้วเปิดอีกหน้าต่าง:

```text
หน้าต่าง 4:  arm remote        → เปิดค้างไว้ (เปลี่ยนโปรแกรมได้: arm remote pick)
```

หน้าต่างนี้แสดงทุกครั้งที่โยกสวิตช์ (`สวิตช์ SWB=U SWD=U`) และผลจากแขน (`แขนรายงาน: 1:ok`)
ถ้ายังไม่ได้เปิด `arm player` ก็เปิดทดสอบสวิตช์ได้ — เห็นผลบนจอแต่แขนไม่ขยับ

**กันสั่งมั่ว:**

- สั่งเฉพาะจังหวะโยก ขึ้น → ลง · สวิตช์ลงค้างไม่สั่งซ้ำ จะเล่นอีกรอบต้องยกขึ้นแล้วโยกลงใหม่
- เปิดระบบตอนสวิตช์ลงอยู่ = ไม่สั่ง (ต้องเห็นสวิตช์ขึ้นก่อน)
- รีโมทดับ/หลุดสัญญาณ = ไม่สั่ง และหลังสัญญาณกลับมาต้องยกสวิตช์ขึ้นก่อน
- แขนกำลังเล่นโปรแกรมอยู่แล้วโยก SWB อีก = ถูกปฏิเสธ (`rejected:busy`) ไม่ซ้อน

`arm remote` เปิด `relay_bridge` (คุยกับ Mega) ให้ด้วย ถ้ายังไม่ได้เปิด — ปิดด้วย `Ctrl+C` ปิดทั้งคู่
รีโมทยังขับฐานได้ตามปกติ (SWA = ARM ล้อ ไม่เกี่ยวกับแขน)

## 3. ปิด

1. ให้แขนกลับท่าพักก่อน: `arm run demo` (จบที่ท่าพัก)
2. `arm off` (ปิดทุกอย่างของแขน — หรือกด `Ctrl+C` ทีละหน้าต่าง)
3. ปิดไฟแขน

## 4. ต้อง calibrate เมื่อไหร่

- ปิดไฟแขน หรือถอดสาย USB ของ Teensy
- แฟลชเฟิร์มแวร์ Teensy ใหม่
- แขนชนอะไร หรือสายพานรูด (ตำแหน่งที่ระบบจำไว้จะไม่ตรงกับแขนจริงแล้ว)

ถ้าไม่ได้เกิดเรื่องพวกนี้ ข้ามขั้น calibrate ไปที่ `arm start` ได้เลย

**ระหว่าง calibrate (ราว 2 นาที):**

- รอบแขนโล่ง สาย USB หย่อนพ้นรัศมีแขน — ฐาน J1 หมุนไปถึง −170°
- log เงียบ หรือขึ้น error / `Failed to acquire lock` ก็ได้ — Teensy ทำต่อจนจบเอง
- **ห้ามกด Ctrl+C จนกว่าแขนจะหยุดนิ่งที่ท่าพัก**

## 5. ปัญหาที่เคยเจอ

| อาการ | สาเหตุ | แก้ |
|---|---|---|
| `Waiting for at least 1 matching subscription(s)` | ตัวเล่นโปรแกรมไม่ได้เปิด | `arm player` ในอีกหน้าต่าง |
| `ระบบแขนเปิดอยู่แล้ว — ห้ามเปิดซ้อน` | มีระบบแขนเปิดอยู่แล้ว | ใช้ตัวเดิม หรือ `arm off` แล้วเริ่มใหม่ |
| `Controller already loaded`, `Unknown header C1/P0/JA` | เปิดระบบแขนซ้อน 2 ชุด | `arm off` → calibrate ใหม่ |
| `path tolerance violation` | สั่งเร็วเกิน มอเตอร์ตามไม่ทัน | ใช้ความเร็วปกติ (0.19) ห้ามเกิน 0.22 |
| สายพานรูด / ท่าเพี้ยน | แขนยื่นไกลแล้วเร่ง-หยุดแรง หรือสายพานหย่อน | ให้ช่างตั้งความตึง → calibrate ใหม่ |
| calibrate แล้วโปรแกรมพัง (USB หลุดกลางทาง) | สัญญาณรบกวนจากมอเตอร์ | รอแขนกลับท่าพัก → `Ctrl+C` → `arm start` |
| `ไม่เจอ Teensy` | สาย USB หลุด/เสียบผิดเส้น | เสียบสาย Teensy เข้า Pi (เส้นที่ใช้ได้) แล้วเปิดไฟแขน |
| โยก SWB แล้วแขนไม่ขยับ | ยังไม่ได้ยกสวิตช์ขึ้นก่อน / SWD ลงอยู่ / ตัวเล่นโปรแกรมไม่เปิด | ดูหน้าต่าง `arm remote` ว่าขึ้นอะไร — ยก SWB, SWD ขึ้นแล้วโยก SWB ลงใหม่ |
| `arm remote` ขึ้น `ไม่เจอ Mega` | Mega ไม่ได้เสียบที่ Pi | เสียบ USB ของ Mega เข้า Pi |
| `arm goto` ขึ้น `ไม่มีโปรแกรม '@...'` | ตัวเล่นโปรแกรมยังเป็นรุ่นก่อนมีคำสั่ง goto | `Ctrl+C` ที่หน้าต่าง `arm player` แล้วสั่ง `arm player` ใหม่ (ครั้งเดียว) |

## 6. คำสั่งเต็ม (ถ้าคำสั่ง `arm` ใช้ไม่ได้)

เข้า container ก่อนทุกหน้าต่าง: `docker exec -it humanoi_ros bash`

```bash
# calibrate / เปิดระบบแขน
ros2 launch ar_hardware_interface ar_hardware.launch.py serial_port:=/dev/serial/by-id/usb-Teensyduino_USB_Serial_13173040-if00 calibrate:=True
ros2 launch ar_hardware_interface ar_hardware.launch.py serial_port:=/dev/serial/by-id/usb-Teensyduino_USB_Serial_13173040-if00 calibrate:=False
# ตัวเล่นโปรแกรม
ros2 launch ar_program arm_program.launch.py
# สั่งงาน
ros2 topic pub --once /arm/run std_msgs/msg/String "{data: demo}"
ros2 topic pub --once /arm/stop std_msgs/msg/Empty "{}"
ros2 run ar_program teach --list
ros2 run ar_program teach <ชื่อท่า>
ros2 run ar_program teach --program <ชื่อโปรแกรม> <ท่า1> <ท่า2> wait=1.0 <ท่า3>
```

MoveIt (นอก container บนเดสก์ท็อป Pi): `bash ~/Humanoi/scripts/arm_moveit.sh`

คำสั่ง `arm` คือ `~/Humanoi/scripts/arm.sh` (alias อยู่ใน `~/.bashrc` ของ Pi)
