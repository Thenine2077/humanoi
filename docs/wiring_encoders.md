# Encoder 4 ล้อ → Arduino Mega → ROS

ความเร็วล้อตั้งด้วยลูกบิด HW-687 ล้อละตัว (relay คุมแค่เดิน/ถอย/หยุด) — encoder ไม่ได้คุมความเร็ว
แต่ใช้ **จูนลูกบิดให้ 4 ล้อหมุนเท่ากัน** แล้วปล่อยไว้ และส่ง **feedback ล้อเข้า ROS** (`/wheel_states`, `/wheel_odom`)

```
encoder YT3806 ×4 ──(A/B)──> Mega A8-A15 ──USB "ENC ..."──> relay_bridge (Pi) ──> /wheel_states /wheel_odom /encoder_raw
                                                   <──"W F F F F"──  /cmd_vel หรือ /wheel_cmd (wheel_tune)
```

เฟิร์มแวร์: `firmware/humanoi_base_mega` (ตัวเดิม + encoder) · โหนด: `humanoi_base/relay_bridge.py`, `wheel_tune.py`
ค่าฐาน: `ros2_ws/src/humanoi_base/config/base.yaml`

## ต่อสาย

| encoder | ล้อ (ตั้งใจ) | A (เขียว) | B (ขาว) | แดง | ดำ |
|---|---|---|---|---|---|
| E1 | FL หน้าซ้าย | A8 | A9 | +12V | GND |
| E2 | FR หน้าขวา | A10 | A11 | +12V | GND |
| E3 | RL หลังซ้าย | A12 | A13 | +12V | GND |
| E4 | RR หลังขวา | A14 | A15 | +12V | GND |

- **ไฟ encoder:** ป้ายบนตัวเขียน DC 8–24V → ใช้ตัวแปลงไฟ (step-down) ตั้ง 12V จ่ายทั้ง 4 ตัว (รวม ~0.2–0.4 A)
  ห้ามใช้ 5V ของ Mega (ต่ำกว่า 8V encoder ไม่ทำงาน) · **GND ของ encoder, ตัวแปลงไฟ และ Mega ต้องต่อร่วมกัน**
- **step-down ใช้กับสายไฟ (แดง/ดำ) เท่านั้น** — สายสัญญาณ (เขียว/ขาว) ห้ามผ่าน step-down
  step-down แปลงไฟเลี้ยงที่ใช้กระแส ส่งสัญญาณพัลส์ผ่านไม่ได้ สัญญาณไปเข้า Mega ตรง (หรือผ่านตัวแบ่งแรงดัน/opto ข้างล่าง)

### ต่อไฟด้วย DC-DC XL4016

```
บัส 24V (+) ──ฟิวส์ 1A──> XL4016 IN+          XL4016 OUT+ (ตั้ง 12V) ──> สายแดง encoder ทั้ง 4 ตัว
บัส 24V (−) ───────────> XL4016 IN−          XL4016 OUT− ──────────> สายดำ encoder ทั้ง 4 ตัว ──> GND ของ Mega

สายเขียว (A) / ขาว (B) ของแต่ละ encoder ──────────────────> ขา Mega ตามตาราง (ไม่ผ่าน XL4016)
```

1. **ตั้งแรงดันก่อนต่อ encoder:** ต่อแค่ขาเข้า หมุนวอลุ่มบน XL4016 วัดที่ OUT+/OUT− ให้ได้ 12V แล้วค่อยต่อ encoder
   (XL4016 รับเข้าได้ถึง 40V ใช้กับบัส 24V ได้ · ขาเข้า/ขาออกด้าน − ต่อถึงกันในบอร์ด จึงใช้เป็น GND ร่วมได้เลย)
2. ต่อสายแดง/ดำของ encoder ทั้ง 4 เข้า OUT+/OUT− (ขนานกัน)
3. ต่อ OUT− เข้า GND ของ Mega (ถ้า GND ของ Mega ต่อลบแบตอยู่แล้ว ก็ร่วมกันอยู่แล้ว)
4. สายสัญญาณต่อตามหัวข้อถัดไป — **ห้ามต่อ OUT+ 12V เข้าขาใดๆ ของ Mega**
- ต่อผิดล้อหรือนับกลับทิศ **ไม่ต้องย้ายสาย** — `arm wheel-check` หาค่า `encoder_map` / `encoder_signs` ให้
- สายสัญญาณเดินห่างสายมอเตอร์/relay ถ้าทำได้ (สัญญาณรบกวนทำให้นับพลาด)

### ต่อสัญญาณตรงเข้า Mega ได้ไหม — เช็กก่อน

Mega รับได้ไม่เกิน 5V ถ้า encoder ปล่อย 12V ออกมาที่สายสัญญาณ ขา Mega เสีย
encoder ตระกูล 3806 ส่วนมากเป็น **NPN open collector** (ดึงลงกราวด์อย่างเดียว ไม่ปล่อยไฟออก) ซึ่งต่อตรงได้
เพราะ Mega เปิด pull-up 5V ภายในให้ — แต่รุ่นนี้หา datasheet ไม่เจอ ให้วัดก่อน:

1. จ่ายไฟ 12V ให้ encoder **โดยยังไม่ต่อสายเขียว/ขาวเข้า Mega**
2. มัลติมิเตอร์วัดแรงดัน สายเขียว ↔ GND แล้วค่อยๆ หมุนแกน encoder
3. อ่านได้ ~0V ตลอด (หรือกระโดดแค่ 0 ↔ ไม่กี่ mV) = open collector → **ต่อตรงได้**
   อ่านได้ ~12V หรือสลับ 0 ↔ 12V = มี pull-up/push-pull ข้างใน → **ห้ามต่อตรง** ใช้ทางใดทางหนึ่ง:
   - **ตัวแบ่งแรงดัน** ต่อสายสัญญาณละชุด (8 ชุด): สายเขียว/ขาว ──10kΩ──┬──> ขา Mega
     แล้วจากจุด ┬ ต่อ 6.8kΩ ลง GND → 12V เหลือ ~4.9V (ถูกและพอสำหรับความเร็วล้อ)
   - **บอร์ด opto** 4 ช่อง 12V เช่น DST-1R4P โหมด common anode — 8 สาย ใช้ 2 บอร์ด ฝั่งออกต่อ A8–A15 + GND ของ Mega

## แฟลชเฟิร์มแวร์

Mega ตอนนี้เสียบอยู่ที่ Pi — ย้าย USB มาเสียบ PC แล้วอัปโหลดด้วย Arduino IDE (บอร์ด Arduino Mega 2560)
**ปิดไฟมอเตอร์ก่อนอัปโหลด** (relay อาจกระตุกตอนรีเซ็ต) เสร็จแล้วเสียบกลับ Pi

เปิด Serial Monitor 115200 ดูได้เลย: บรรทัดแรก `READY humanoi_base_mega enc=x4` แล้วมี `ENC ...` ทุก 50 ms
หมุนล้อด้วยมือ ค่านับของ encoder ล้อนั้นต้องเปลี่ยน · ตัวเลข 4 ตัวท้าย (นับพลาด) ควรเป็น 0

## ขั้นตอนครั้งแรก

1. **ยกฐานให้ล้อลอยพ้นพื้น** (วางบนกล่อง)
2. หน้าต่าง 1: `arm base` — เปิดค้างไว้
3. เปิดรีโมท, **SWA ลง**, ปล่อยคันโยก (Mega อยู่โหมด ROS)
4. หน้าต่าง 2: `arm wheel-check`
   - หมุนทีละล้อ FL → FR → RL → RR ล้อละ 2 วิ แล้วถามว่าล้อหมุนไปทางเดินหน้าไหม (ดูด้วยตา ตอบ y/n)
   - ได้ `encoder_map` / `encoder_signs` → ตอบ y บันทึกลง `base.yaml` → **ปิด/เปิด `arm base` ใหม่**
   - ล้อไหนหมุนกลับทาง → แก้ `INVERT` ในเฟิร์มแวร์ (ค่า encoder ที่ได้ใช้ต่อได้)
5. `arm wheel-tune` — 4 ล้อหมุนเดินหน้าค้าง แสดงทุกวินาที เช่น
   ```
   [  5s] FL   60.1 ( -0.4% ✓)  FR   64.0 ( +6.0% ลด)  RL   57.0 ( -5.6% เพิ่ม)  RR   60.5 ( +0.2% ✓)  | เฉลี่ย 60.4 rpm ต่างสุด 11.6%
   ```
   ปรับลูกบิด HW-687 ของล้อที่ขึ้น `ลด` / `เพิ่ม` ทีละนิด รอ 2–3 วิ จนทุกล้อเป็น ✓ (ต่างไม่เกิน ±1.5%) แล้ว Ctrl+C
   - อยากได้ความเร็วตามที่กำหนด: `arm wheel-tune 60` (เทียบกับ 60 rpm แทนค่าเฉลี่ย)
6. `arm wheel-tune back` — เช็กตอนถอยหลังด้วย (มอเตอร์บางตัวเดิน/ถอยเร็วไม่เท่ากัน)
7. วางลงพื้นแล้วเช็กอีกรอบสั้นๆ (มีน้ำหนักกด ความเร็วเปลี่ยน): ขับตรง 2–3 m ดู `/wheel_states`
   หรือ `ros2 run humanoi_base wheel_tune tune --seconds 4` บนพื้นที่โล่ง

## ค่าที่ต้องรู้ก่อนใช้ odometry (`/wheel_odom`)

- `counts_per_rev` = ค่านับต่อ **รอบล้อ** — 1440 ถ้า encoder หมุนรอบเดียวกับล้อ (ต่อแกนตรง)
  ถ้ามีเฟือง/สายพานทดระหว่าง encoder กับล้อ วัดเอง: ทำเครื่องหมายที่ล้อ, `ros2 topic echo /encoder_raw`,
  หมุนล้อด้วยมือ 1 รอบพอดี → ค่านับที่เปลี่ยน = counts_per_rev
- `track` / `wheelbase` ใน `base.yaml` ยังเป็นค่าเดา — วัดระยะกึ่งกลางล้อ ซ้าย-ขวา / หน้า-หลัง แล้วแก้
- mecanum ลื่นตอนสไลด์/หมุน odometry จากล้ออย่างเดียวคลาดได้ — ต่อไปค่อยรวมกับ lidar (rf2o) / IMU
  `publish_odom_tf` ปิดไว้ ไม่ให้ชนกับ TF ของ rf2o

## แก้ปัญหา

| อาการ | ดู |
|---|---|
| `wheel-check` บอกไม่มี encoder ไหนนับ | ล้อหมุนไหม — ไม่หมุน = relay/ไฟมอเตอร์/ลูกบิด · หมุน = encoder ไม่มีไฟ 12V / GND ไม่ร่วม / สายหลุด |
| encoder ตัวอื่นนับด้วย | สาย A/B ข้ามล้อ หรือสัญญาณรบกวนจากสายมอเตอร์ |
| `นับพลาด` ขึ้นตอนหมุนเร็ว | สัญญาณช้า (บอร์ด opto) หรือรบกวน → ตั้ง `ENC_EDGES = 2` ในเฟิร์มแวร์ (แล้ว counts_per_rev = 720) |
| `Mega อยู่โหมด RC / DISARMED / NO_SIGNAL` | รีโมทต้องเปิด, SWA ลง, ไม่จับคันโยก |
| rpm ของล้อติดลบตอนเดินหน้า | `encoder_signs` ยังไม่ได้ตั้ง → `arm wheel-check` |
