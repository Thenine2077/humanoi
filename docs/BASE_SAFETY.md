# ความปลอดภัยของฐานล้อ — กันชน lidar ชั้น Mega

ฐานหยุดเองได้ 4 ชั้น ชั้นล่างสุด (Mega) ทำงานแม้ Pi ค้าง

| ชั้น | ทำงานเมื่อไร | หยุดเมื่อ |
|---|---|---|
| Mega | ตลอด | SWA ขึ้น · รีโมทดับ/หลุด · ROS เงียบเกิน 0.5 วิ |
| **Mega + กันชน lidar** | `arm base` (ค่าเริ่ม) | คำสั่ง **รีโมทหรือ ROS** ที่พาไปทิศที่มีของ ใกล้กว่า 0.30 m · Pi/relay_bridge เงียบ |
| relay_bridge | `arm base` | ไม่มีคำสั่ง 0.5 วิ · ไม่มี lidar = ห้ามทุกทิศ |
| base_motion | `arm drive` / `arm mission` | ของในทาง 0.35 m = หยุดรอ (โล่ง 1 วิไปต่อ, 15 วิเลิก) |

## กันชน lidar ทำงานยังไง

1. relay_bridge ฟัง `/scan` → ทุกทิศ (หน้า หลัง ซ้าย ขวา หมุน) ดูว่ามีจุดในกรอบทางที่จะไปไหม
   - เดินหน้า/ถอย/สไลด์: กรอบกว้างกว่าตัวหุ่นข้างละ 5 cm ยื่นออกไป `stop_dist` 0.30 m จากขอบตัว
   - หมุน: วงที่มุมตัวหุ่นกวาด + 5 cm
2. ส่ง `G <บิต>` ให้ Mega ทุก 50 ms (1 หน้า 2 หลัง 4 ซ้าย 8 ขวา 16 หมุน)
3. Mega คิดว่าคำสั่งล้อตอนนี้ (จากรีโมทหรือ ROS) พาตัวหุ่นไปทิศไหน — ไปทิศที่ห้าม = หยุดทุกล้อทันที
   - **ถอยหนี/สไลด์หนีของได้เสมอ** ห้ามแค่ทิศที่มีของ
   - ของออกไปไกลเกิน 0.35 m ต่อเนื่อง 0.5 วิ ถึงปลด (กัน relay กระพริบตอนของอยู่ตรงขอบ)

| สถานการณ์ | Mega ทำอะไร |
|---|---|
| Mega เพิ่งบูต ยังไม่ได้ยิน Pi | ไม่กัน — ขับด้วยรีโมทอย่างเดียวได้เหมือนเดิม |
| `arm base` เปิด แต่ไม่ได้เปิด `arm lidar` | **ห้ามทุกทิศ** (ล้อไม่หมุนเลย) |
| lidar หลุดกลางทาง | ห้ามทุกทิศภายใน ~0.5 วิ |
| Pi ค้าง / relay_bridge ตาย / สาย USB Mega หลุด / Ctrl+C `arm base` | Mega ห้ามทุกทิศเองใน 0.5 วิ (`GUARD:LOST`) |
| อยากขับต่อตอน LOST (ไม่มี lidar) | **โยก SWA ขึ้นแล้วลงหนึ่งครั้ง** → ขับได้โดยไม่มีกันชน จน Pi กลับมาส่งใหม่ |
| `arm base noguard` | ไม่กัน (ส่ง `G OFF`) — ใช้ตอนยกล้อจูน/ทดสอบเท่านั้น |

ดูสถานะ: หน้าต่าง `arm base` บอก `กันชน: ห้าม F---T` ทุกครั้งที่เปลี่ยน · topic `/base_guard` · Mega ส่ง
`GUARD:ON F----` / `GUARD:HOLD F----` (กำลังหยุดล้อไว้) / `GUARD:FREE` / `GUARD:LOST` / `GUARD:OFF` ใน `/motor_state`

ค่าตั้ง: `ros2_ws/src/humanoi_base/config/base.yaml` หัวข้อ `guard:` · Mega: `GUARD_TIMEOUT`, `GUARD_LOST_STOPS`
ใน `firmware/humanoi_base_mega/humanoi_base_mega.ino` (`GUARD_LOST_STOPS = false` = LOST แล้วขับได้เลย ไม่ต้องโยก SWA)

## ทดสอบก่อนแฟลช (ไม่ใช้ฮาร์ดแวร์)

```bash
bash tools/mega_sim/run_tests.sh
```
build เฟิร์มแวร์ Mega ตัวจริงเป็นโปรแกรม Linux (`tools/mega_sim`) ต่อ relay_bridge ตัวจริงผ่านพอร์ตจำลอง
ใส่ lidar/รีโมทปลอม แล้วเล่นทุกกรณีในตารางข้างบน (ต้องมี g++ + ROS 2 Jazzy: WSL Ubuntu-24.04 หรือ container บน Pi)

## แฟลช + ทดสอบบนหุ่นจริง

แฟลชเหมือนเดิม (docs/wiring_encoders.md §แฟลชเฟิร์มแวร์) — **ปิดไฟมอเตอร์ก่อน** ไฟล์ `guard.h` ต้องอยู่โฟลเดอร์เดียวกับ .ino
และต้องอัปเดต relay_bridge บน Pi พร้อมกัน (เฟิร์มแวร์เก่าไม่รู้จัก `G` — ไม่พัง แต่ไม่กัน)

1. ยกล้อ: `arm base noguard` → `arm wheel-check` ยังผ่านเหมือนเดิม
2. `arm base` (ไม่เปิด lidar) → รีโมทดันคันโยก ล้อต้องไม่หมุน · หน้าต่าง base ขึ้น "ไม่มีค่า lidar"
3. วางพื้น `arm lidar` + `arm base` → คนยืนห่าง 1.5 m ขับรีโมทเข้าหาช้าๆ → ต้องหยุดเอง
   **วัดระยะที่เหลือจริง** (ไหลต่อหลังตัด relay) → ปรับ `stop_dist` ให้หยุดห่างพอ
4. ตอนหยุดอยู่ ดึงคันโยกถอย → ต้องถอยได้
5. คนเดินตัดหน้าตอนวิ่ง → หยุด · คนเดินพ้น → ปล่อยคันโยกแล้วดันใหม่ วิ่งต่อได้
6. ถอด USB lidar ตอนวิ่ง → หยุดใน ~0.5 วิ · Ctrl+C `arm base` → รีโมทขับไม่ได้ → โยก SWA ขึ้น-ลง → ขับได้

## ข้อจำกัด (ยังไม่ได้แก้)

- lidar เห็นแค่ระนาบความสูงเดียว: ของเตี้ยกว่า (เท้า กล่องบนพื้น) หรือสูงกว่า (ขอบโต๊ะยื่น) มองไม่เห็น
- ด้านหลังมีมุมเงาเสา — ถอยหลังในมุมนั้นไม่ถูกกัน
- กรอบคิดจากขนาดฐาน (53 × 42.5 cm) — แขนพับแล้วยื่นเลยฐาน ต้องขยาย `guard.footprint` (และ `scan_mask`)
- ระยะหยุดจริง (relay + ไหลต่อ) ยังไม่ได้วัด — ซิมทดสอบได้แค่ตรรกะ ไม่ใช่มอเตอร์
- ยังไม่มีปุ่ม E-stop ตัดไฟมอเตอร์
